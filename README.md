# Apparel Infosys - ETL, Forecasting, and MLOps Project

This repository contains a comprehensive end-to-end project designed to demonstrate expertise in ETL, data engineering, machine learning forecasting, and MLOps. The project is built around an apparel brand's data, featuring workflows orchestrated with Airflow, machine learning model tracking with MLFlow, containerization with Docker, and monitoring using Prometheus and Grafana.

---

## **Features**
- **ETL Pipeline**: Data extraction, transformation, and loading using PySpark and Python.
- **Forecasting Models**: Implementation of multiple forecasting models with Scikit-learn.
- **MLOps**: Model tracking with MLFlow, containerization with Docker, and orchestration with Airflow.
- **Monitoring**: Real-time metrics visualization with Prometheus and Grafana.
